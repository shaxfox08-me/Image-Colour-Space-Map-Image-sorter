# Image-Colour-Space-Map-Image-sorter
html file that allows you to upload images that can then be sorted into a colour space, such as LCH or HSL, the layout of the images can then be tweaked and then the final result can be exported
You can also upload images and sort them by hue, value or saturation, again adjusting the layout and then exporting.

Using the wallpaper builder zip you can turn the png output into a pan and zoomable tiled wallpaper that can be used on your desktop with wallpaper engine on steam
